# Security

The AI connector's security review is kept with its code, where it is updated after every review:
**[Connector security review](https://github.com/Christian-open-library/Connector/blob/main/docs/security-review.md)**.

The connector only reads the library. It was put through a structured security review carried out with Claude,
Anthropic's AI; no outside firm has audited it.

To report a problem privately, use **Report a vulnerability** on the
[Security tab of this repository](https://github.com/Christian-open-library/.github/security), or write to
hello@christianopenlibrary.org.
